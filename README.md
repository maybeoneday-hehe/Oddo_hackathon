SMART COLLEGE EVENT MANAGEMENT SYSTEM
Project Description
The Smart College Event Management System is a full stack web application designed to manage college events in a simple and organized way.

Students can register themselves, view upcoming events, search events, enroll in events, and track the events they have registered for. Administrators can log in, create new events, update existing events, delete events, view all registrations, and monitor event participation through an analytics dashboard.

The project uses a local SQLite database, dynamic REST APIs, proper validation, responsive Bootstrap UI, and Chart.js for dashboard analytics.

Sample Project Question
Develop a Smart College Event Management System that allows students to register, view upcoming events, enroll in events, and track their registrations. Administrators should be able to create, update, delete events, and monitor participation statistics. The system must use a local database, dynamic data, proper input validation, responsive UI, and REST APIs.
